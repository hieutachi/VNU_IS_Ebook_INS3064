SECTION 1: CORE THEORY (KEY CONCEPTS)

1.1 What Are Variables?

Variables are named storage locations that hold data values in your PHP programs. A variable must start with a dollar sign ($) followed by a name that follows specific rules. Variables allow you to store, retrieve, and manipulate data efficiently throughout your scripts.

Key Point: All variables in PHP start with $ symbol. Variable names are case-sensitive: $name ≠ $Name. Use meaningful names like $studentName instead of $s.

1.2 Variable Naming Rules & Best Practices

Rule Valid Examples Invalid Examples
Must start with $ symbol $name, $age, $total name, age (no $)
Can contain letters, numbers, underscores $var123, $my_var, $myVar $my-var, $my var, $123var
Cannot start with number (after $) $var1, $number2 $1var, $2number
Case-sensitive (important!) $var, $Var, $VAR (3 different variables) Treating $name same as $Name causes errors
Best Practice: Use camelCase for variable names ($studentName, $totalPrice, $isActive). This improves readability and follows PHP conventions.

1.3 Introduction to Data Types

PHP is a dynamically typed language, meaning you don't need to declare a variable's type beforehand. PHP automatically determines the type based on the value assigned to it. Understanding data types is essential for writing correct programs.

PHP supports 8 data types grouped into three categories:

  1. Scalar (Primitive) Types: String, Integer, Float, Boolean - each holds a single value
  2. Compound Types: Array, Object - each holds multiple values
  3. Special Types: NULL, Resource - special purpose types

1.4 String Data Type

A string is a sequence of characters enclosed in quotes. PHP supports both single quotes (' ') and double quotes (" ").

Key Difference:
  • Double Quotes: Support variable interpolation (embedding variables). "$name is here" displays actual value.
  • Single Quotes: Treat everything literally. '$name is here' displays literal "$name is here".
<?php // Double quotes - interpolation $name = "Alice"; echo "Hello, $name"; // Output: Hello, Alice // Single quotes - no interpolation echo 'Hello, $name'; // Output: Hello, $name // Concatenation with dot operator $greeting = "Hello" . " " . "World"; // "Hello World" ?>

1.5 Integer Data Type

An integer is a whole number (no decimal point) that can be positive, negative, or zero. PHP integers have a range from approximately -2.1 billion to +2.1 billion.

Rules for Integers:
  • Must have at least one digit
  • Must NOT have a decimal point
  • Can be either positive or negative
  • Can be specified in decimal (base 10), hexadecimal (base 16), or octal (base 8) notation

1.6 Float Data Type

A float (also called "double") is a number with a decimal point or in exponential form. Floats are used for calculations requiring decimal precision.

<?php $price = 19.99; // Float $pi = 3.14159; // Float $scientific = 1.2e5; // Exponential: 120000 $tiny = 0.0001; // Very small float ?>

1.7 Boolean Data Type

A boolean represents one of two states: true or false. Booleans are primarily used in conditional statements and comparisons. When displayed with echo, true shows as "1" and false shows as nothing (blank).

Falsy Values (evaluate to false): false, 0, 0.0, "" (empty string), "0", null, and empty arrays. All other values are truthy.

1.8 NULL Data Type

NULL represents a variable with no value. A variable is NULL if it has been unset or never assigned a value. It's different from empty string "" or zero 0.

1.9 Array Data Type (Introduction)

An array stores multiple values in a single variable. PHP supports both indexed arrays (numeric keys) and associative arrays (named keys). Arrays are essential for storing collections of related data.

1.10 Understanding Type Juggling

PHP performs automatic type conversion (type juggling) when needed. For example, when you add a string number to an integer, PHP converts the string to an integer.

<?php $result = "5" + 3; // Result: 8 (integer) // PHP converts "5" to 5 $calculation = "10.5" * 2; // Result: 21 (float) // PHP converts "10.5" to float ?>
Important: While type juggling is convenient, it can cause bugs. Always use explicit type casting for clarity: (int)"5" or (float)"10.5"
