## 📖 Introduction

This is a **complete learning material** for the course **Multimedia Design and Web Development (INS3064)**, designed in a "hands-on" style with:

- ✅ Easy-to-understand theory explanations
- ✅ Real-life examples and illustrations
- ✅ Detailed code samples with comments
- ✅ Practice exercises after each session
- ✅ Real-world projects throughout
- ✅ Self-assessment worksheets

---

## 🎯 Learning Outcomes

After completing this course, you will:

1. **LO1**: Understand and master basic PHP syntax
2. **LO2**: Build dynamic websites with PHP
3. **LO3**: Design and manage MySQL databases
4. **LO4**: Write SQL queries from basic to advanced
5. **LO5**: Connect PHP with MySQL to build web applications
6. **LO6**: Handle errors and secure web applications
7. **LO7**: Manage sessions with Cookies & Sessions
8. **LO8**: Use jQuery to enhance interactivity

## 📖 How to Use This Material

### For Students:

1. **Start here** — Read `00_start_here.md` for how to use the material
2. **Then the overview** — Read `00_course_overview.md`
3. **Study sequentially** — Follow the order from Session 1 → Session 15
4. **Type code** — Don't copy/paste
5. **Run immediately** — Test after each change
6. **Do exercises** — After each session
7. **Complete worksheets** — Self-assessment
8. **Integrate projects** — Build project week by week

### For Instructors:

- Each session = 3 hours (Theory + Practice)
- Ready-to-run code samples
- Slides extracted from markdown
- Exercises with answers
- Printable worksheets

## 💡 Study Tips

- Type code instead of copy/paste
- Run code after each change
- Read error messages carefully
- Do exercises immediately

### ❌ Don't:

- Copy code without understanding
- Do multiple sessions at once
- Skip exercises
- Study alone
- Wait until the end to code
