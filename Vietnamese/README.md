Đây là **tài liệu học tập đầy đủ** cho môn **Multimedia Design and Web Development (INS3064)**, được xây dựng theo phong cách "cầm tay chỉ việc" với:

- ✅ Bài tập thực hành sau mỗi buổi
- ✅ Dự án thực tế xuyên suốt

## 🎯 Mục tiêu học tập (Learning Outcomes)

Sau khi hoàn thành khóa học, bạn sẽ:

1. **LO1**: Hiểu và sử dụng thành thạo cú pháp PHP cơ bản
2. **LO2**: Xây dựng website động với PHP
3. **LO3**: Thiết kế và quản lý Database với MySQL
4. **LO4**: Viết truy vấn SQL từ cơ bản đến nâng cao
5. **LO5**: Kết nối PHP với MySQL để xây dựng ứng dụng web
6. **LO6**: Xử lý lỗi và bảo mật ứng dụng web
7. **LO7**: Quản lý phiên làm việc với Cookies & Sessions
8. **LO8**: Sử dụng jQuery để tăng tính tương tác
